<h2>📌 Project Overview</h2>

<p>
    The <strong>Banking Loan & Risk Analysis Dashboard</strong> is an
    interactive data analytics project developed using
    <strong>Power BI</strong>.
</p>

<p>
    The project focuses on analyzing loan applications, customer profiles,
    loan performance, and financial risk to generate meaningful business
    insights.
</p>

<hr>

<h2>🎯 Project Objectives</h2>

<ul>
    <li>Analyze loan application trends</li>
    <li>Analyze approved and rejected loans</li>
    <li>Identify high-risk customers and loans</li>
    <li>Monitor loan amounts and repayment performance</li>
    <li>Analyze loan defaults</li>
    <li>Identify important risk factors</li>
    <li>Support data-driven banking decisions</li>
</ul>
